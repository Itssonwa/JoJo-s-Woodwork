JoJo’s Woodwork Website

Features
- Multi‑page layout (Home, About, Contact, Orders, Thank You page)
- Organized folder structure for CSS, JS, and images
- JavaScript order submission with redirect to a styled Thank You page
- Responsive design basics

Running the Project
1. Install Visual Studio Code.
2. Add the Live Server extension.
3. Open the project folder in VS Code.
4. Right‑click `index.html` → Open with Live Server.
5. Your browser will open at `http://127.0.0.1:5500/index.html`.
